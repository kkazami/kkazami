### 🎓 LMS-CDM — Learning Management System

[![LMS-CDM](https://github-readme-stats.vercel.app/api/pin/?username=kkazami&repo=LMS-CDM&theme=midnight-purple&hide_border=true)](https://github.com/kkazami/LMS-CDM)

</div>

A **cross-platform monorepo** Learning Management System built for CDM colleges (ICS, IBE, ITE).

| Platform | Stack |
|----------|-------|
| 🌐 Web | Next.js + TypeScript + Tailwind CSS |
| 📱 Mobile | Expo React Native |
| 🖥️ Desktop | Electron |
| 🗄️ Database | PostgreSQL + Prisma ORM |
| ⚙️ Infra | Docker + Turborepo + pnpm workspaces + Vercel |

🔗 **Live:** [lms-cdm.vercel.app](https://lms-cdm.vercel.app) &nbsp;|&nbsp; 📂 **Repo:** [kkazami/LMS-CDM](https://github.com/kkazami/LMS-CDM)
